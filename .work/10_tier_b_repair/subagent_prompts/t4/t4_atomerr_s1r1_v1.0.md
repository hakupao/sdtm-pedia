## 每条核什么 (两半都要核, 与 `TRIAGE_ATOM_ERR` 层相同)
1. **① 原子 ≠ PDF**: 原子 verbatim 确实与 PDF 该处原文不符 (漏词 / 多词 / 错字 / 错值 / 列错位 / 把别处内容拼进来 / PDF 根本没有这句). 写出具体差在哪 (原子写的 vs PDF 写的).
   - 只是空白、换行、Markdown 表格管道符、粗体、弯直引号这类归一化差异, **不算**原子抽错.
   - 表格行 / 表头逐格比; 值类 (日期 / 数字 / 代码 / 变量名) 一个字符都要对. 列对齐、折行、字形 (引号 / 破折号 / 连字符) 有疑问以渲染页为准.
2. **② KB = PDF**: KB 在该原子所属域 / 章节的文件里按 PDF 写对了 (逐字或逐格一致; 归一化同上). 给出 KB 文件:行. 包里的 KB 指针可能偏或缺 (有 1 条没给), 判 NOT_HOLD 之前必须自己在所属文件里 Grep 找一遍.

## 判定 (三选一; 口径同 `t4_supp_fullcheck_v1.0.md`)
- **HOLDS**: ① 与 ② 都成立.
- **NOT_HOLD**: 任一半不成立. 说明栏必须写:
  - 哪一半不成立: `①不成立` (原子其实与 PDF 一致, 没抽错) / `②不成立` (KB 与 PDF 不符: 缺内容 / 值不同 / 位置错 / 改义) / `①②都不成立`;
  - PDF 是什么、原子是什么、KB 是什么 (各 ≤ 25 词);
  - 仅 `①不成立` 时, 再写按标签定义 KB 对 PDF 是逐字 (EXACT) 还是等价不逐字 (EQUIVALENT) — 这只是事实描述, 改不改标签不由你定.
- **UNVERIFIABLE**: 文本层 + 渲染页都判不了. 写明缺什么.
- 拿不准不要判 HOLDS; 不要因为 "看起来大概对" 放过.
- 已登记的 PDF 笔误 (`work/t2_pdf_typo_registry.jsonl`) 造成的 KB ≠ PDF 不算 ② 不成立, 但必须在说明栏写 `涉登记 <id>`, 并写明: PDF 印的是什么、KB 是什么、登记的 handling 是什么. (这类条目主控会单列给主人, 不由你改判.)
- 顺手看到的 KB 内容问题 (样本之外) 单列, 不算样本判定, 不修.
