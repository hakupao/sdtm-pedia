## 方法
- **起点**: 每域在 bbox 中找 `<XX> – Specification` 行 (SUPPQUAL 为 `8.4.1 Supplemental Qualifiers`; 跳过 TOC p1-19), 只解析其下方.
- **表头**: 含 Variable+Controlled+Core 的行 + 其下全由表头词组成的连续行 = 表头带 (只丢整行全是表头词的行, 修 speccmp2 把正文 "or"/"Role" 当表头词删掉的缺陷); 列 x 取表头词 xMin; 无表头续页沿用上页列 x.
- **止点**: 首个 `In this column` 脚注 / `XX – Assumptions|Examples|Description` / `N.N.N 标题` 行 → 表结束; `©` 页脚只截本页不终止 (修 sc2 止点缺陷). 未遇止点自动翻下一页 (修 "两行表头页漏首变量 / 无表头续页不解析").
- **续行**: 续页首个变量名之前的正文并入上一变量 (修 sc2 漏跨页续行). **上标**: 字高 <0.7×中位数 且底线高于同行邻词 2pt 以上才算上标并剔除 (全库只命中 DM p63 RACE "guidance²" 的 ² 与 ETHNIC "guidance¹" 的 ¹; 渲染 p63 确认, 已登记 DM T-1 (S-SPEC1 #5/#6), KB 两处均为 ²); 行内阅读顺序按底线 (yMax) 分组, 小字号斜体词 (IS p229 "not", LB p244 "Analysis method") 不再错位.
- **比较**: NFKC + 弯引号/dash/项目符号归一 + 去全部空白后相等 (PDF 折行连字符 "CHILD- PUGH" 自动等价); 另跑空白敏感比 (PDF `\w- \w` 折行连字符合并后与 KB 逐字比) → `out/wsdiffs.json`.
- **CT 分类**: PDF 括号短名 `\(([A-Za-z0-9_]+)\)` vs KB `C\d+`; 短名→C-code 用 `SDTM Terminology.xlsx` (2022-09-30, codelist 行 = Codelist Code 空) 的 CDISC Submission Value 交叉核, 多 codelist 按单元格顺序逐个对; 另用 `SDTMIG_v3.4.xlsx` Variables!H 作第三来源核 KB C-code.
- **交叉验证**: 同一 bbox 上跑修正版 `sc2w.py` / `speccmp2.py` (每域 spec 页范围), 把它们报的 CT 差异单元格与 ct_extract 的 PDF 值对齐 (结果见 "交叉核").
