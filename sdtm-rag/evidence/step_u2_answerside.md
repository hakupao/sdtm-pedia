### 2.1 这对自毁条款 3 意味着什么

条款 3 原文 (先于数据写死, **本单元未改一字**):

> 答题侧卡片 48 题: judge 逐题下降 **≥ 3 题** 或均值下降 **> 2.0pt** ⇒ doc 通道生产默认 OFF。

**纯噪声已经达到「下降 3 题」** ⇒ 🔴 **该条款的「逐题」那一半在这把尺子上不具判别力**
(它在 doc 通道根本没开的情况下就会触发)。**均值**那一半仍有判别力: 噪声 0.65pt vs 阈值 2.0pt,
余量约 3 倍。

按 spec §5.3.1 写死的处置:
- ✅ **必须大声写明该条款的逐题半不具判别力** —— 本节即是。
- ⛔ **不许**反过来拿"这在噪声范围内"去消化一次真回归。
  ON 臂的下降题数**与地板并列呈现**, 由用户裁定, 不由本文件替他消化。

### 2.2 若没有空臂会发生什么 (记账)

空臂是 2026-08-12 才加进 spec 的 (§5.3.1), 起因是 Task 3b 报告的检索非确定性。
**没有它, ON 臂只要下降 3 题就会被判成真回归, 直接把 doc 通道按死在生产 OFF** ——
而那 3 题可能一题都不是 doc 通道造成的。

这与本单元反复抓到的是同一个母题, 只是方向相反:

| 位置 | 形态 |
|---|---|
| Task 1 分组标题 / Task 2 引擎实参对调 / Task 3 装配块 / Task 7 judge 两臂互换 | **该红不红** (装饰断言) |
| **自毁条款 3 的逐题半** | **总在红** (噪声即触发) |

两头都是同一件事: **判据没有被证明能区分它声称要区分的两种情况。**

### 4.1 ⛔ 自毁条款 3 判定 — **触发**

| 比较 | 逐题降 | 均值 | 阈值 `≥3 题 或 >2.0pt` |

- **逐题那一半不具判别力** —— 空臂自己就 3 题 (spec §5.3.1 写死的处置: 必须大声写明)。
- **均值那一半有判别力** —— 地板 1.39 < 阈值 2.0 < 实测 2.78/4.17, 且对**两个独立 OFF 臂
  各自比较都超阈, 方向一致**。
- ⇒ **条款 3 在有判别力的那一半上触发。** 阈值自始至终未改。
  条款字面后果 = **doc 通道生产默认 OFF**。**由用户裁定, 本文件不替他消化。**

**⚠ 引用纪律**: 必须写成「**触发了**」。**不许**写成「未触发」「在噪声范围内」「降幅不大」。

## 4. 本文件看不见什么 (硬规矩 19)

1. **单模型单温度** —— 换模型可能翻转 (U1 `q57` 的先例: n=18 单模型的判定, 已写明换模型可能翻)。
2. **空臂 n=1 对** (一对 OFF-OFF) ⇒ 噪声地板本身只有一个样本, 它是**点估计不是区间**。
3. **强制 `corpus=study`** ⇒ 不含判库损耗; 生产 `auto` 下那 3 道被判 cdisc 的题不在本表。
4. **judge 是 LLM** ⇒ judge 自身的抖动混在噪声地板里, 本表无法把它与答题模型的抖动分开。
5. **doc 席位固定 N=8** ⇒ 其余档的答题侧影响未测。
6. **`parse_ok=False` 的题单列不混进均值** (spec §5.3), 本轮卡片侧空臂 0 例。
