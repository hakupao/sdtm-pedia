## 1. 闸做什么

V3 §4 第 3 条 / N1 §2.2 #4 / §2.6 #11 三条同型: **底层事实为真** (来自 builder 写进 label 的
块表元数据「同一画面: …」), 但被挂上『画面目視判読 p.NN』—— 那一页的图上并没有这条注记。
页号越界闸只比对页号集合, N1 的「添付頁の範囲では」规则只约束否定断言, 两者都看不见它。
本闸只打这道缝: **一条画面主张里点到的实体, 是不是真的印在那一页的文本层上**。

判定 5 类 (逐主张单元):

| 类 | 含义 |
|---|---|
| `PAGE_GROUNDED` | 单元里的实体全部出现在所引页的文本层 (实体为零也算, 另计 `no-ent`) |
| `LABEL_ATTRIBUTED` | 有实体不在页上, 但在该页 **label 的元数据** 里 (同 form 同 hidden_items 的折叠块集合, 由页索引复算) = 不可能来自图像 |
| `OFF_PAGE` | 既不在页上也不在 label 元数据里 |
| `OUT_OF_RANGE` | 引用的页不在本次附页集合内 |
| `AMBIGUOUS` | 无法归属该页 (没写 PDF 名而两份 PDF 都附了同页号; 或页号范围读不出) |

`AMBIGUOUS` 同样进 flagged 清单与非零退出码: 没归属上的主张放进「无罪」侧, 会让闸的绿色
失去「查过了」的含义。

**实体集** (主张单元里可核验的东西, 也就是闸能查的全部):

| 种类 | 怎么算被点名 | 怎么算在页上 |
|---|---|---|
| activity | OID token 边界匹配, 或活动短名 (≥3 字) 去空白子串 | 同左, 对着页文本层 |
| form | OID token 边界匹配, 或 form 名 (≥3 字) 子串 | 同左 |
| **项目组名 (annotated 页)** | 该页 `page_groups` 里**非空**的组名 (≥2 字) 子串; 组 OID 不参与 | 组名是否印在该页文本层 |

组名是 N3 写进 label 的「本頁の項目グループ順」的内容, 属**页索引元数据**。所以:
页上有见出し的组 → `PAGE_GROUNDED`; **续接组** (见出し在前一页) 出现在引用该页的主张里
→ `LABEL_ATTRIBUTED`。这正是 N3 复审预言的捏造形态, 而 N3 的合格判据 (LABEL = 0) 若没有
组名进实体集就看不见它。名字为空的枠 (「(無題)」) 不进实体集 (没有可照合的字符串)。
索引里没有 `page_groups` (N3 之前的版本) 时静默跳过; 条目里没有 `continued` 键时按
「非续接」读 —— 判定本身只看页文本层有没有那个名字, 所以这个默认值不改变结论。
名字照合同样取**极大匹配** (枠名也会互相包含)。

**闸不是判分**: 标红只说明「这条出处用图像说不出来」, 不等于捏造已确定; 标绿也只说明
「该页文本层印着这些实体名」。

## 4. 相对 PLAN §7 的实现细化 (都是 pattern 级)

PLAN §7 只写了「句/条目切单元 + 实体照合」。按字面实现后 18 份上标红 12 条、真捏造只中 2 条。
逐条定位成因后加了 8 条**通用**规则, 每条都有单元测试:

| 规则 | 为什么 (成因, 非个案) |
|---|---|
| 卡片出处 `[Source: …]` 也算出处边界 | 答案一行里常同时有卡片事实与画面主张; 不切开就把卡片列举的活动算进画面主张 |
| 单元**止于**自己的出处 | 出处是后置归属, 其后的文字不归它 |
| 页号只在**连续**时并入同一出处; 读不出的范围判 AMBIGUOUS | `〔…p.34〕 ただし、これは p.34–43 …` 会把块范围当引用页, 正确的但书反被判 OUT_OF_RANGE |
| 页列举的分隔符含「と / および / and / &」 | `p.29 と p.74` 不认分隔符就只剩 1 页, 双页比较型主张会被误判 |
| 相邻出处并成一条归属 | 它们是一份页清单, 拆开会让同一段正文只按第一页核验 |
| 页**自身的宛名** (所属块的 activity/form) 不算 label 捏造 | 通道对每张附页都在 label 抬头写了它是谁的画面; 复述宛名不是捏造。且 workflow 页文本层一个 OID 都没有 (S0 实测) |
| 名字照合取**极大匹配** | 活动短名互相包含, 裸子串会让写一个长名 = 点名 3–4 个活动 |
| **「対応表より」只剥句子不剥整句**, 且只在出处行本身无内容时才上溯, 上溯时取整块 | 见下 |

**「対応表」规则单独说明 (召回依赖它)**: 出处常单独后置在「名称は…対応表より。〔出处〕」
这样的纯归属行上, 承载正文在上面。判断「这一行有没有内容」时必须把这个归属**短语**剥掉,
否则该行看起来有内容, 单元不上溯, **3 条召回里的第 1 条 (V3) 与第 3 条 (N1 gpt-sol T6) 都会
丢**。反过来, 若把含「対応表」的**整句**都算成零内容, 则「X 是对应表所载 Y, 而画面上排着 Z」
这类混在句也会被判零内容, 单元无谓上溯并吞掉上一行的实体 (实测假阳性)。所以只剥短语
(`_TABLE_ATTRIB_RE`), 长度阈值作用在剩下的部分。两个方向各有一条测试, 关掉任一方向都会红。

## 5. 画面同一性概念规则 (第二层网, 可关)

**为什么需要**: 已知 3 条捏造里, V3 那条把活动名意译成中文 (简体汉字 ≠ 页索引里的日语名),
实体照合解析不出任何实体。纯实体层召回 **2/3** (`--no-sameness-rule` 可复现)。

**规则 (概念, 不是句式清单)**: 一条主张同时满足
① 同一性词 (日/简/繁: 同じ・同一・同様・同等・共通・共有・共用・一致・相同・同样・完全相同・
まったく同じ …) 出现在 ② 指「画面」的名词 (画面・表示・レイアウト・画面構成・页面・ページ) 的
25 字窗口内, 且 ③ 不是「一个画面**之内**」的说法 (同一画面内/上/に…), 也不是同一性挂在
内容 (項目・値・順序…) 上, 且 ④ **该单元引用的附页 < 2 张** —— 引了两张已附页面互相比较,
是图像本身能说的, 不必借 label。
依据是构造性事实: **一张页面的图像不可能证明另一个活动的画面与它相同**; 该同一性只存在于
builder 写进 label 的「同一画面: …」。判定前先剥掉出处标记本身 (『画面目視判読』里就含
「画面」, 不剥的话写个出处就凭空立起一个画面名词)。

**换说法测试 (复审指定 14 条)**: 8 条必须响 (共有 / 共用 / 同様 / 一致 / まったく同じ /
完全相同 / 同样的 / 共用されている, 均为**不含可解析实体**的句子, 确保只有本规则能发火),
6 条必须沉默 (同一画面上 / 同じ画面に…並ぶ / 同一の画面に…表示される / 同一画面内 /
页面实有文字「…と同一である」的引用 / 同一性挂在「同じ項目」上)。另加一条: 引用 2 张附页的
「p.A と p.B は同じ画面です」必须沉默。全部 green。

**代价 (实测)**: 概念化后在 18 份上多标 1 条 (§3.3 #7) —— 一条**带否定**的 hedge
「无法确认为同一连续画面」。买到的是 8 条换说法的覆盖。判据内, 不再对着这 18 份调语汇。

## 6. 已知盲点

1. **只看文本层**。图里的线框、面板边界、灰显读不到 —— judge 记过的 2 条面板边界合并型
   捏造, 原理上检不出。
2. **不看句子极性**。「X 在这页上」与「X **不在**这页上」对闸是同一件事。两条假阳性
   (§3.3 #5 #7) 都出自这里, 其中 #7 说明极性盲点同样影响同一性规则 ——「不能确认相同」
   与「相同」在闸眼里没有区别。
3. **实体只有 activity / form 与 annotated 页的项目组名**。item OID 不进实体集: workflow
   页文本层一个 OID 都没有 (S0 实测), 放进去会让每条主张都 OFF_PAGE。代价是
   「item OID 张冠李戴」型捏造检不出。
   组名这条另有两处边界: ① 只对 annotated 页生效 (workflow 侧页索引没有组信息);
   ② 判定只看页文本层有没有那个名字 —— 页上印了见出し但 `pdftotext` 没抽出来 (图形化
   标题等) 会误报, 反之组名恰好出现在页上别处会漏报。
4. **覆盖率不满**: 90 条主张单元里 29 条 (32%) 一个实体都点不到, 闸只能放行; 实际能核验的
   约 68% (组名进实体集前是 57%)。
5. **单元只向前扩, 不向后**。出处是后置归属, 所以其后的文字按设计归下一条 —— 但实测
   29 条实体为零的单元里有 **13 条**, 紧跟出处之后就出现了实体 (表中 `ent-after`)。
   若模型把出处写在主张**之前**, 闸就看不到那些实体。
6. **折叠集合是复算的超集**。索引里同 form 同 hidden_items 的块全算折叠, 但 builder 对
   **问题点名的活动不折叠**, 那次 label 上并没有它的名字。方向偏松: 少数本该 OFF_PAGE 的
   会记成 LABEL, 标红与否不变。
7. **页归属靠附页集合**。同页号两份 PDF 都附且出处未写 PDF 名 → AMBIGUOUS (本轮 0 条)。
8. **中文意译的活动名与索引里的日语名不通约**, 实体层看不见。第二层只在「同一性」这一个
   概念上兜底, 其他句型的意译仍是盲区。

- **盲点 (N3 复测新增): 否定极性。** 「这页是另一张表单, 不是本题表单」这类正确否定, 实体正因为不在页上才被写进句子 → 被标 OFF_PAGE (c2r_n3 1/40)。闸不读极性; 不放宽判据, 由 judge 复核。

- **N3 a2 追加盲点**: 单元切分会吞掉归属作用域 (a2 gpt-terra T1); 同一性词规则对「同一性被否定」的泛指句误触发 (a2 gpt-terra T6)。假阳性 a1 1 → a2 3。**面板合并型 contradicted 两轮零召回** —— 本闸只挡 LABEL 型来源捏造, 不是画面主张总体真伪的闸。
