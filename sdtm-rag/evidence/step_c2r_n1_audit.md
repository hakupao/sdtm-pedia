## 5. 混杂因素 (confounds) — 可比性如实说

1. **corpus 路由回落到 `both`**: 6 份 N1 答案的 `routed_corpus` 全是 `both`, V3 对应 3 份是 `study`。
   成因是路由模型今日在供给侧被拒。`both` 只会**多**挂通用语料, 对 study 事实是稀释而非污染;
   逐份检查未见通用语料内容混入 study 结论 (T1 两份都把标准侧映射整段隔离并标为推测)。
   **对三条判据的结论无实质影响**, 但 T1 两份因此多了一段标准内容, 长度与 V3 不完全可比。
2. **T3 的 annotated 页集变了**: V3 是 ann 3 页 + wf 3 页, N1 是 ann **2** 页 + wf **4** 页。
   掉的那一页与本题项目无关 (是另一种药的投与状况页) → 掉了不减损;
   加的那一页是**又一个块首页**, 与原有三页同型 → **多了一次踩坑机会**, 即 N1 的 T3 条件比 V3 **更难**而非更易。
   结论: T3 的 4/4 不是靠页集变简单换来的; **但严格说 T3 不是同输入复测**。
3. **T1 / T6 页集与 V3 逐字相同**, `pdf_trigger` 也一致 (T1/T3 = R1, T6 = R3)。这两题可比性好。
4. **最重要的一条 — 被测的不是犯错的那个模型**: V3 §4 五条 contradicted 里,
   「附页缺席 → 整块缺席」那两条 **100% 出现在 opus-5 上**; gpt 家在 V3 里同型错误数本来就是 **0**。

   「只附了块中的一页 / 添付頁の範囲では / 不能外推到整块」句式, 其中一份还逐字写出了三个块的页区间;
